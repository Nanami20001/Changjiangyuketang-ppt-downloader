# 长江雨课堂课件下载器

面向长江雨课堂的 Windows 课件工作台。登录后，可以把已加入课程的课件批量保存到电脑，不用逐门打开课程下载。桌面版独立运行，无需安装浏览器脚本。

桌面版作者与维护者：[Nanami20001](https://github.com/Nanami20001)。

## 主要功能

- **课件库**：按课程浏览，搜索课件，筛选本次扫描新增的内容。
- **批量导出**：将图片型课件合成为 PDF；已有直链的课件按原格式保存。
- **下载管理**：暂停、继续或取消当前任务，重试失败或缺页的任务，定位已保存的文件。
- **本地归档**：自定义保存位置、按课程建文件夹，并保留扫描历史。

## 一键启动

- **有 Windows 64 位便携版**：双击 `RainclassroomDownloader-2.0.0-Windows-x64.exe`，无需安装 Node.js 或配置环境。
- **只有源码**：先安装 Node.js 22.12 或更新版本，解压源码后双击 `启动下载器.cmd`。缺少依赖时会自动联网安装，后续还是双击同一个文件。

## 使用方法

1. 首次使用时，点击右上角 **登录雨课堂**，在弹出的官方网页中完成登录。登录状态有效时无需重新登录。
2. 在 **课件库** 点击 **开始扫描**，展开课程浏览课件，也可以搜索名称或筛选 **本次新增**。
3. 勾选课件并点击 **下载选中**。在 **下载任务** 中，暂停会保留已读取的页面，取消会让队列继续处理下一项。
4. 如需更改保存位置或按课程归档，打开 **保存设置**。默认保存到 Windows 的「下载」文件夹。

图片型课件按页导出为 PDF。状态显示「部分完成」时，可在任务列表查看缺少的页数并重试。同名文件会自动编号。原桌面版的扫描记录、保存设置和登录会话可以继续使用。

此软件供个人学习使用。课件归授课教师及学校所有，使用时请遵循课程的分享要求。课件索引、扫描历史、下载记录和设置保存在本机。

## 开发与打包

在 Windows 上使用 Node.js 22.12 或更新版本。

- `npm ci` 安装依赖。
- `npm start` 运行工作台。
- `npm test` 检查增量扫描、旧数据迁移、设置保存和下载队列。
- `npm run dist:win` 生成 `dist/` 下的 Windows 64 位便携版。

分享时只需发送生成的 `RainclassroomDownloader-2.0.0-Windows-x64.exe`，不用附带 `win-unpacked`、源码或 `node_modules`。便携版只打包简体中文、繁体中文和英语的运行环境语言资源。

桌面版通过内置登录窗口连接雨课堂，课程扫描、下载队列与 PDF 导出由桌面程序处理，界面与登录网页隔离。

## 项目结构

- `desktop/main.cjs`：桌面入口，管理窗口、登录和界面操作。
- `desktop/workspace-preload.cjs`：界面调用桌面功能的桥接层。
- `desktop/services/`：雨课堂接口、课件库与旧数据迁移、下载队列和文件导出。
- `desktop/renderer/`：工作台页面、样式和交互。
- `build/icon.ico`：Windows 便携版图标。
- `dist/`：生成的 Windows 便携版。
- `tests/`：桌面版测试。
